# Odin Books

A simple library and reading-tracker app built as part of the Odin Project curriculum.

## Overview

Odin Books is a small web app for managing a personal book collection. Users can add books, mark them as read or unread, and keep track of what they want to read next. This project is designed to practice DOM manipulation, data handling, and building a clean user interface with JavaScript.

## Usage

- Enter a book's title, author, page count, and reading status
- Click the add button to save the book
- Use the app to track which books are finished or still in progress
- Remove any book you no longer want in your library
